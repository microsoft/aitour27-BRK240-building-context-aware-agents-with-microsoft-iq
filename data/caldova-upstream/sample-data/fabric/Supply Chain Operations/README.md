# Fabric definitions

- `SupplierSM (SemanticModel)/`
- `Supplier Performance (Report)/`

Deploy these definitions from the repository root through
`provision/fabric/create_fabric_semantic_model.py` and
`provision/fabric/create_fabric_reports.py`. They use canonical supplier IDs
`sup-001` through `sup-015` and require the lakehouse created by
`provision/fabric/create_fabric_lakehouse.py`.
